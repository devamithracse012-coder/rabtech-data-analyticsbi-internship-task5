# Task 5 – Interactive Dashboard & KPI Visualizations

## Retail Sales Dashboard

**Internship:** RabTech Academy – Data Analytics & Business Intelligence  
**Tool:** Microsoft Power BI

## Objective

The aim of this task is to create a simple dashboard to understand retail sales performance using important KPIs and charts.

## KPIs

The dashboard includes:

- **Total Revenue**
- **Total Customers**
- **Average Order Value**
- **Estimated Profit**

## Visualizations

The dashboard contains:

- KPI Cards
- Revenue by Category
- Monthly Revenue Trend

## Dataset

The dashboard uses the cleaned retail sales dataset prepared in Task 2.

The dataset contains information about customers, products, categories, dates, quantities and revenue.

## Key Analysis

- **Total Revenue:** Shows the overall sales revenue.
- **Total Customers:** Shows the number of unique customers.
- **Average Order Value:** Shows the average revenue per transaction.
- **Estimated Profit:** Shows the estimated profit.
- **Revenue by Category:** Compares sales across different categories.
- **Monthly Revenue:** Shows how revenue changes each month.

## Data Assumption

The dataset does not contain an actual cost field. Therefore, the profit shown is an **estimated value** based on the assumption used in Task 2.
